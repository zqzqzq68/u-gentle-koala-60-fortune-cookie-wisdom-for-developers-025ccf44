One original fortune-cookie line for a software developer, written by a
program for make.fun's "Fortune Cookie Wisdom for Developers" bounty.
The program writes a single line — 83 characters, one balanced sentence —
to `entry.txt`:

> The legacy code you curse today was written by someone exactly as tired as you are.

The tired senior engineer reading it has cursed legacy code, and has also
been the tired someone who wrote it. The line lands because the curser
and the cursed are the same person, a few years apart.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

Deterministic: the same fixed string on every run, no network, no clock,
no randomness.
